C · By area, with role start pages

Sidebar by area like A. "Start here" gives each role a reading path through it, so newcomers get B's guidance without duplicated pages. My recommendation.

Every task page would follow the same shape: what you need first, numbered steps with screenshots, what happens afterwards (who gets notified, what the student sees), and common mistakes.
