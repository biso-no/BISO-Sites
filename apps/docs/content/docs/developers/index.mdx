This section is for a consultant or new hire who is starting cold. It explains how the platform fits together, where each part runs, how to ship changes, and where to look when something stops working.

Start with [Your first day](/developers/start-here/your-first-day). It gives the reading order and the access you need. Then read [What BISO runs](/developers/start-here/what-biso-runs) and [Getting access](/developers/start-here/getting-access).

To ship a change or keep the platform running, read [Deploying](/developers/keep-it-running/deploying), [Scheduled jobs](/developers/keep-it-running/scheduled-jobs) and [Secrets and environment](/developers/keep-it-running/secrets-and-environment).

If you're on the BISO board and need to hire someone, read [If you're hiring someone](/developers/start-here/if-youre-hiring-someone).
