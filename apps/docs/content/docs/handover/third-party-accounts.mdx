# Third-party accounts

This page complements [ownership-and-accounts](/docs/handover/ownership-and-accounts).
That page is about *who holds the master credentials*. This page is about
*what BISO is paying for* — subscriptions, plan tiers, monthly rates,
renewal cycles.

Like the ownership page, this is a template. Every row needs to be filled
in by the current IT Manager at handover.

looking at the right account.
</Callout>
