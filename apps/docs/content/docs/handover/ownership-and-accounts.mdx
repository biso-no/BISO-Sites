# Ownership and accounts

This page is the answer to the question "what does BISO actually own, and
who has the keys?" It is a template. The current IT Manager must fill it
in before handing over.

If any row below is blank or stale at handover, the platform has a
single-person dependency that needs fixing.

<Callout type="warn">
**To be filled in by the current IT Manager** before leaving the role.
Every `[FILL IN]` below is a piece of institutional knowledge that BISO
will lose if you don't write it down.
</Callout>

## Handover checklist (sign-off)

At the moment of handover, the outgoing IT Manager should walk the
incoming person through each section and tick:

- [ ] Incoming person has tested login to every row above.
- [ ] Two-person redundancy exists for every "critical" row (domain,
      Appwrite, Azure AD Global Admin, GitHub org owner, password
      manager).
- [ ] Outgoing person's personal accounts have been *removed* from team
      memberships (replaced with role accounts where possible).
- [ ] Any personal devices with cached secrets / SSH keys have been
      wiped of BISO material.
- [ ] Signed off by: [FILL IN: outgoing IT Manager] and [FILL IN:
      incoming IT Manager]. Date: [FILL IN].
