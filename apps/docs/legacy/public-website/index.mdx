# Public Website

The public website is what people land on when they type **[biso.no](https://biso.no)** — students looking for events, applicants reading job ads, members buying merch, alumni reading news. Internally it's the Next.js app at `apps/web` and runs on port 3000 in development.

This section explains the site from two angles in the same page:

- **What does the user see?** — for admins who publish content and want to know how it shows up.
- **How does it work?** — a quick technical pointer for developers, with links into the architecture docs for depth.

If you only have time for one page, read [Routing and pages](/docs/public-website/routing-and-pages) — it lists every URL on the site and what lives there.

## How the site is built (in one paragraph)

`apps/web` is a Next.js 15 App Router project with React 19. Almost everything is a Server Component — pages fetch data directly from Appwrite (through [`@repo/api`](/docs/packages/api)) and render HTML. Interactive bits (cart, locale switcher, forms) opt into Client Components with `"use client"`. Editor-built pages are stored as a JSON block document and rendered by [`@repo/editor`](/docs/packages/editor). Everyone who visits the site gets an Appwrite session immediately — anonymous if they haven't logged in — so the site can safely use the same data layer for guests and members alike. See [Authentication and sessions](/docs/public-website/authentication-and-sessions) for the details.
